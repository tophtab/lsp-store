LSP Store is an updater and browser for LSPosed modules. It reads the same repository as LSPosed Manager (modules.lsposed.org), so the updates it offers match what Manager shows.

Features:
- Browse and search the repository, with recently updated and most starred tabs.
- Installed modules grouped into updates, up to date and not in the repository; update one or all of them.
- Module pages with readme, hook scope, release notes and release history, plus a stable / pre-release / all channel switch.
- Downloads that pause, resume and keep going when you leave the page; install with any registered APK installer, or silently with root.
- Favourites, recently viewed, ignored updates, and linking repository modules to installed apps that are not in it.
- Mirror selection with a latency test.
- Module description translation (Google, LibreTranslate, DeepL, Microsoft).
- Library backup and restore as JSON.
- 14 languages, light and dark themes, AMOLED black and Material You colours.
