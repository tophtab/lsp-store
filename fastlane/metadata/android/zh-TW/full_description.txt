LSP Store 是 LSPosed 模組的更新與瀏覽工具，讀取與 LSPosed Manager 相同的儲存庫 (modules.lsposed.org)，因此提供的更新與 Manager 一致。

功能：
- 瀏覽並搜尋儲存庫，提供最近更新與最多星號分類。
- 已安裝模組依可更新 / 已是最新 / 不在儲存庫中分組，支援單一或一鍵全部更新。
- 模組詳情頁顯示 readme、Hook 作用域、更新日誌與發佈歷史，可在穩定版 / 預先發佈版 / 全部三種通道間切換。
- 下載支援暫停、續傳，離開頁面也不會中斷；可交給任何已註冊的 APK 安裝器，root 下可靜默安裝。
- 收藏、最近瀏覽、忽略更新，並可將儲存庫模組關聯到不在儲存庫中的已安裝應用程式。
- 鏡像選擇與延遲測試。
- 模組簡介翻譯（Google、LibreTranslate、DeepL、Microsoft）。
- 以 JSON 備份與還原本機資料。
- 14 種語言、淺色與深色主題、AMOLED 純黑與 Material You 取色。
