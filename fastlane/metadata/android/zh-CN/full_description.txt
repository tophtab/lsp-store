LSP Store 是 LSPosed 模块的更新与浏览工具，读取与 LSPosed Manager 相同的仓库 (modules.lsposed.org)，因此给出的更新与 Manager 一致。

功能：
- 浏览并搜索仓库，提供最近更新与最多星标分类。
- 已安装模块按可更新 / 已是最新 / 不在仓库中分组，支持单个或一键全部更新。
- 模块详情页展示 readme、Hook 作用域、更新日志与发布历史，可在稳定版 / 预发布版 / 全部三档通道间切换。
- 下载支持暂停、断点续传，离开页面也不会中断；可交给任意已注册的 APK 安装器，root 下可静默安装。
- 收藏、最近浏览、忽略更新，并可将仓库模块关联到不在仓库中的已安装应用。
- 镜像选择与延迟测试。
- 模块简介翻译（Google、LibreTranslate、DeepL、Microsoft）。
- 以 JSON 备份与恢复本地数据。
- 14 种语言、浅色与深色主题、AMOLED 纯黑与 Material You 取色。
