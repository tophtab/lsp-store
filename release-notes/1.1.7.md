Fixed:

- The Installed list now recognises modules that use the modern libxposed declaration (for example Wren). They declare nothing in the manifest and instead ship `META-INF/xposed/` markers inside the APK, so they used to be filtered out as plain apps.
- The scan now checks split APKs as well as the base APK, so modules installed as app bundles are not missed; the installed module count follows.
