Added:

- A Download retention setting now appears below Concurrent downloads, with 0, 1 week, 2 weeks, 4 weeks and ∞ options. The default is ∞, keeping downloads forever.

Reduced:

- Exported APKs are cleaned up automatically after the selected retention period, in both the default and custom download folders. Selecting 0 removes existing copies and stops keeping new ones. Installation continues normally, and other files are left untouched.

Fixed:

- An export task that finishes quickly no longer prevents the APK from being exported again later.
