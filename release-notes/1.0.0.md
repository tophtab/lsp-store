首个公开版本。

- 浏览、搜索并安装 LSPosed 官方仓库中的模块，已安装模块可单个或批量更新。
- 模块详情页包含 readme、Hook 作用域、更新日志与历史版本；可逐模块跟随预发布。
- 下载支持暂停、断点续传与前台服务；可交给设备上任意 APK 安装器，root 下可静默安装。

- 从本版本起，应用随官方模块索引分发，也可在 LSPosed Manager 中直接安装与更新；
  应用本身不 Hook 任何目标，无需激活。

---

First public release.

- Browse, search and install modules from the official LSPosed repository; update
  installed modules one by one or all at once.
- Module pages show the rendered readme, hook scope, changelog and release history;
  pre-release tracking can be enabled per module.
- Downloads support pause, resume and a foreground service, and can be handed to any
  APK installer on the device; silent install with root.
- 14 languages, light / dark / AMOLED themes and Material You colors.
- Starting with this release the app is distributed through the official module
  index and can be installed or updated from LSPosed Manager. It hooks nothing and
  needs no activation.
