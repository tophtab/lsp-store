- Repository modules can be hidden by keyword: a match in the title, package name or summary removes the module from browsing lists, while installed modules and update checks are unaffected. The ignore list shows each keyword's current match count.
- Background checks now accept any custom interval from 1 to 168 hours. Long-press a preset to enter an hour value; the current custom interval is shown in the settings row.
- The installed list and detail pages load faster: unchanged app scans are reused, only relevant packages are queried, and app icons and long READMEs load in the background instead of blocking the page.
- Downloads and index refreshes are more reliable: progress and notification updates are throttled, stale task callbacks cannot overwrite a newer task, overlapping index refreshes are coalesced, and caches are written atomically so clearing them cannot resurrect old data.
- Auto-update summaries now use a silent notification channel. The Simplified and Traditional Chinese description for Silent install now states that installation and updates run through root permissions.
