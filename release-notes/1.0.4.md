模块的「更新于」现在显示真正的发版时间，不再被 star 顶起来。

- 仓库/首页卡片和详情页的时间改用最新一个 release（正式版、预发布或快照）的发布
  时间，和 GitHub、LSPosed 仓库里看到的一致。
- 有人点 star、改 README 或改元数据时，GitHub 会把仓库的 `updated_at` 一起刷新；
  以前这个时间被当作「更新于」，所以会出现「1 小时前更新」但实际两天没发版的情况。
- 「最近更新」排序同样按发版时间；从未发过版的模块不再显示更新时间，并排在已发版
  模块之后。

---

Module pages now show the real release time instead of a star bump.

- The time on repository/home cards and the detail header comes from the newest
  release (stable, pre-release or snapshot), matching what GitHub and the LSPosed
  repository show.
- A star, a README edit or a metadata push refreshes GitHub's repo-level
  `updated_at`; it used to be displayed as "updated", so a module that had not
  released in days could claim it was updated an hour ago.
- "Recently updated" sorts by release time too. Modules that never published a
  release show no time and sort after the ones that did.
