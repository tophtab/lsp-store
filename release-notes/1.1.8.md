修复：

- 单个模块更新时不再禁用整个已安装页面的按钮：其他模块随时可以更新，取消系统安装器后也不需要等待 180 秒或重启应用。
- 被系统安装器取消的安装会自动对账，模块重新回到更新列表；下拉刷新也会立即触发一次对账。
- 下载完成的 APK 会保存一份到公共 `Download/LSP_Store`，可在文件管理器中直接找到；设置里的「清除已下载的 APK」会同时删除私有缓存和这份副本。

减少：

- 最低支持版本提升到 Android 10（API 29）。

Fixed:

- Updating a single module no longer disables the whole Installed page: every other module stays actionable, and dismissing the system installer no longer requires a 180-second wait or an app restart.
- Installer hand-offs that were cancelled are reconciled automatically, so the module returns to the update list; pull-to-refresh also runs a reconciliation immediately.
- Finished APKs are saved to the public `Download/LSP_Store` folder, where a file manager can find them. "Clear downloaded APKs" removes both the private cache and this copy.

Reduced:

- The minimum supported version is now Android 10 (API 29).
