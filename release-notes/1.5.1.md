修复：

- 关联到仓库模块、或安装包名与仓库包名不一致的模块，在「全部更新」里不再停在「等待安装」：安装阶段按仓库包名更新该行，成功与失败都会正确显示，轮到安装之前也仍可取消。

Fixed:

- Modules linked to a repository entry, or installed under a package name that differs from the repository one, no longer stick at "waiting to install" during Update all: the install stage updates the row under the repository package, reports success and failure correctly, and can still be cancelled before the hand-off.
- Clearing downloaded APKs in Settings > Storage while a transfer is running no longer wedges the install chain: the wait ends as a cancellation and releases its download slot.
- The module page now recognises a same-versionCode re-upload as an update, matching the Installed tab.
- After opening Installed from an update notification, rotating the screen or recreating the UI no longer forces the user back to that page.
