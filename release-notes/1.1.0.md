下载支持断点续传，更新过程也能逐条看到进度。

增加：

- 每条更新行显示自己的下载百分比、等待安装和安装状态，下载中可以单独取消；「全部更新」运行中也可以随时停止。
- 设置 → 下载 可以设同时下载的数量（1–5，默认 3），批量更新和模块页安装共用这个上限。
- 设置 → 翻译 新增「自动翻译」开关：打开模块详情时自动翻译描述，目标语言跟随应用语言。
- 平板和其他宽屏窗口改用侧边导航栏，手机仍保持底部导航栏。

减少：

- 无。

修复：

- Wi-Fi 断开、切换网络或应用进程被杀后，下载会从已经下载的部分继续，不再从头重下或直接失败。
- 重新输入搜索词时，结果列表从顶部开始显示，不再停在上一组结果的滚动位置。
- 设置页顶栏多余的空白副标题。

Downloads survive a dropped connection, and each update shows its own progress.

Added:

- Every update row shows its own download percentage, waiting/installing state, and can be cancelled on its own; "Update all" can be stopped while it runs.
- Settings → Downloads sets how many APKs download at once (1–5, 3 by default); batch updates and module-page installs share the limit.
- Settings → Translation gained an "Auto-translate" switch: a module's description is translated when its page opens, into the app language.
- Tablets and other wide windows use a navigation rail; phones keep the bottom bar.

Removed:

- None.

Fixed:

- When Wi-Fi drops, the network switches or the app process is killed, the download resumes from the bytes already on disk instead of starting over or failing.
- A new search query starts the results at the top instead of keeping the previous scroll offset.
- The empty subtitle in the Settings top bar.
