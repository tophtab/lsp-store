增加：

- 首次引导新增「读取应用列表」授权。部分国产系统（HyperOS、ColorOS 等）在 Android 的包可见性之外还单独管控应用列表，允许后才能识别已安装的 LSPosed 模块。

减少：

- 首次引导不再要求先授予「安装未知应用」权限才能完成；仍可在引导中提前授权，第一次安装时也会照常引导开启。

---

Added:

- Onboarding now offers an "Installed apps" permission. Some Chinese ROMs (HyperOS, ColorOS and others) gate the installed-app list separately from Android's package visibility; allowing it lets LSP Store find your installed LSPosed modules.

Removed:

- Onboarding no longer blocks completion on the install-unknown-apps permission. You can still grant it there, and the first install keeps prompting for it as before.
