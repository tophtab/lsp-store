修复：

- 模块不再因为「在这台设备上用不了」而被永久隐藏：这个结论不再被保存，每次打开模块页、每次检查更新都重新判断，所以升级系统、换框架、作者替换同名安装包之后都能自动恢复。
- 旧版本留下的「不适用」记录在升级后自动失效：模块重新回到更新列表，详情页的安装按钮也不再被历史结论锁死。
- 已经稳定安装过的模块，不会仅因为新版本的文件名像配套应用就被判为不能装：会先打开安装包确认，确认是本模块就正常安装。
- 「全部更新」里遇到这一版没有可装的文件时算跳过，不再计入失败汇总；下一次检查重新判断，不做任何记录。
- 旧备份文件里带着「不适用」记录时不再被整份判为格式错误，收藏、链接、跳过版本都能正常恢复。

Fixed:

- A module is no longer hidden for good because it "does not fit this device": that call is not stored any more. It is recomputed on every module page and every update check, so an OS upgrade, a framework upgrade or a re-uploaded APK all recover by themselves.
- A stored "not applicable" verdict from an older build stops applying after the upgrade: the module returns to the update list and the module page no longer keeps its install button disabled.
- A module that installed fine before is not rejected just because a new build's file name looks like a companion app: the archive is read first, and it installs normally when it turns out to be the module.
- "Update all" treats "this release has nothing for this device" as a skip instead of a failure, and the next check decides again with nothing recorded.
- A backup file written by an older build that contains a "not applicable" entry is no longer rejected as malformed; favourites, links and skipped versions restore as usual.
