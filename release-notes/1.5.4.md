Fixed:

- A `minSdk` above the device no longer blocks the install: the detail page stops greying the APK out and stops disabling the install button - it only leaves a "Requires Android 15+ (you have 11)" line on the asset row, and the system installer makes the call.
- One false verdict went with it: since Android 11 the platform refuses to describe an archive whose `minSdk` is above itself, which made such APKs look like "not an Xposed module" and get rejected outright. The manifest inside the archive is read instead, so the real package name and Xposed declaration still decide.
- The two numbers in that `minSdk` hint now use the same unit; no more "Requires Android 35+ (you have 14)" mixing API levels with system versions.
