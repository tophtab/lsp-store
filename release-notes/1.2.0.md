增加：

- 「全部更新」把 LSP Store 自身排到最后安装：其余模块全部交给安装器后才更新本应用，替换自身 APK 时的进程重启不会再打断整批更新。

减少：

- 无。

修复：

- 更新模块时不再因为 `module.prop` 里声明了更高的 libxposed API 而拒绝安装：按加载器的实际策略（`targetApiVersion` + `assets/xposed_init`）判断，声明值只参与排序并显示为警告。
- 识别 Vector 的 manager 包名（`org.matrix.vector.manager`），并修正版本号到 libxposed API 的映射：1.10/1.11 是 API 100，Vector 2.0 / 2.1 / 2.2 分别是 100 / 101 / 102。

Added:

- "Update all" now installs LSP Store itself last: every other module reaches the installer first, so the process restart that replaces the store's own APK can no longer cut the batch short.

Reduced:

- None.

Fixed:

- Modules are no longer refused because `module.prop` declares a newer libxposed API: the loader's actual policy (`targetApiVersion` + `assets/xposed_init`) decides, and the declared value only affects ordering and shows as a warning.
- Vector's manager package (`org.matrix.vector.manager`) is recognized, and the version-to-libxposed-API mapping is corrected: 1.10/1.11 are API 100, while Vector 2.0 / 2.1 / 2.2 are 100 / 101 / 102.
