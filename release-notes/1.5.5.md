增加：

- 仓库首页与作者页的模块卡片可以三秒长按直接忽略，不用再进详情页找菜单，也不弹确认框；
  普通点击和滚动不会误触发。

修复：

- 多 APK 的模块不再需要手动选变体：已安装的模块跟已安装的那份走（包名、ABI、libxposed 代际、minSdk），
  未安装的模块跟设备走（ABI、LSPosed API、厂商 OS 版本、minSdk）；设备也分不出来时选「原版构建 → 下载量最高 → 文件名」。
- 「全部更新」不再跳过变体分不出来的模块，详情页与已安装页也不再弹「请选择一个变体」的对话框。
- 详情页资源列表会把默认包标成「推荐」，标签顺序调整为 ABI → API → minSdk。

Added:

- Holding a module card in the repository or an author page for three seconds ignores that module, with no
  detour through the detail page's menu and no confirmation; taps and scrolling never trigger it.

Fixed:

- Modules that ship several APKs no longer ask you to choose: an installed module follows the build already on
  your device (package, ABI, libxposed generation, minSdk), a new install follows your device (ABI, LSPosed API,
  vendor OS version, minSdk). When the device cannot tell the builds apart, the plain build wins, then the most
  installed one, then the file name.
- "Update all" no longer skips modules whose variants it cannot tell apart, and the detail/installed pages no
  longer show the "choose a variant" dialog.
- The detail page's resource list marks the default APK as recommended and orders its tags ABI → API → minSdk.
